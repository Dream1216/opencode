# P7.6 Question shadow PostgreSQL Store

P7.6 moves only the Question Command Gateway shadow Store from process memory
to the existing PostgreSQL EventStore. The V1 Question service remains the
production source of truth.

## Runtime boundary

```text
V1 Question command
  -> production SQLite/EventV2 result
  -> sampled Question Command Gateway shadow
  -> PostgreSQL Question aggregate append/read
  -> matched/diverged/error
  -> PostgreSQL shared breaker
```

The Store uses a dedicated internal tenant so shadow aggregates cannot be read
as an organization resource. PostgreSQL sequence checks make retries
idempotent and prevent two processes from committing different terminal
decisions.

## Configuration

```bash
OPENCODE_EXPERIMENTAL_QUESTION_COMMAND_GATEWAY_SHADOW=true
OPENCODE_QUESTION_SHADOW_STORE_BACKEND=postgres
OPENCODE_QUESTION_SHADOW_STORE_DATABASE_URL=postgresql://...
OPENCODE_QUESTION_SHADOW_STORE_TENANT_ID=tenant_question_shadow_global
OPENCODE_QUESTION_SHADOW_STORE_DATABASE_MAX=2
```

Roll out at 1% before returning to 5%. Do not enable PostgreSQL Session
projection or the durable worker in the same release.
